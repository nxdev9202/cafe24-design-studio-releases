# Cafe24 Design Studio — 설치 파일

카페24 스마트디자인을 대체하는 데스크톱 앱의 설치 파일 배포 저장소입니다. 소스 코드는 비공개 저장소에서 관리합니다.

최신 버전은 [Releases](https://github.com/nxdev9202/cafe24-design-studio-releases/releases/latest)에서 받습니다.

| 운영체제 | 파일 |
|---|---|
| macOS (Apple Silicon) | `cafe24-design-studio-<버전>-mac-arm64.dmg` |
| Windows 10/11 (64비트) | `cafe24-design-studio-<버전>-win-x64-setup.exe` |

설치한 뒤에는 앱이 새 버전을 확인해 알림을 띄우고, [지금 업데이트]로 바로 업데이트합니다. 모든 파일에는 SHA-512 체크섬(`.sha512`)이 함께 올라가며, 앱은 설치 전에 이 값을 검증합니다.
